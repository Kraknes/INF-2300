## Deployment

To deploy the server run the following in the directory of the simulation.py file:

```bash
  python3 simulation.py
```

or in some cases:

```bash
  python simulation.py
```

This will run the simulation. 

Simulation will be done when the string "Finished!" is printed in the terminal.

### Configure chance

To change the packet size, packet number, seed number, seed randomization,chances of either drop, delay or corruption, or delay time, these settings can be found in the config.py file. Change the values of these constants to your liking.
