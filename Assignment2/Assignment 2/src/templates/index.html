TODO List

Instructions:

This site will handle your TODO list.

You will get 7 options to use on your TODO list

  1. Submit Text Entry to List:
    2. Sends text entry to server that will append to "TODO" list.
  2. Get Text Entry from List:
    3. Request to get specific text entry from "TODO" list with ID number.
  3. Change Text Entry in List:
    4. Changes a text entry in "TODO" list with ID number.
  4. Delete Text Entry in List:
    5. Deletes a text entry in "TODO" list with ID number.
  5. Click to Get List:
    6. Displays all entries of text in "TODO" list.
  6. Click to Remove List:
    7. Removes all entries in the "TODO" list.
  7. Click on "Done"
    8. Changes a text entry to "Done" to represent completion of activity
